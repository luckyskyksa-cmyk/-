# لاكي سكاي (Lucky Sky) — برنامج إدارة الديون والمحلات

برنامج ويب داخلي واحترافي لإدارة ديون المحلات، بواجهة عربية (RTL) بتصميم أبيض/أخضر.
تُحفظ كل البيانات في **خادم مركزي** (قاعدة بيانات دائمة)، فيعمل من عدة أجهزة (2–3)
في نفس الوقت، بدون فقدان البيانات، ولمدى الحياة.

## المميزات

- **المحلات**: إضافة / تعديل / حذف / بحث، مع ترتيب تلقائي حسب الأعلى ديناً.
- **صفحة المحل**: تسجيل بضاعة (دين)، تسجيل دفعة (نقدي/شبكة/تحويل)، بضاعة مرتجعة،
  وتحديد أصناف وتسجيلها كفاتورة خارجية (تُخصم من الإجمالي وتتلوّن)، وحذف المحدد.
- **حساب تلقائي** للرصيد المستحق وضريبة القيمة المضافة (نسبة قابلة للضبط).
- **لوحة تحكم**: إجمالي الديون، المُسدّد الشهري، الديون الجديدة، وترتيب المحلات، وأحدث الحركات.
- **التقارير**: تقرير شهري (مُسدّد/سلف/مرتجع/ضريبة/رصيد) قابل للحفظ PDF عبر الطباعة، وكشف حساب لكل محل.
- **استيراد إكسل**: رفع ملف `.xlsx/.xls/.csv` (20,000+ صف) مع مطابقة الأعمدة تلقائياً واستيرادها.
- **حماية البيانات**: نسخة احتياطية تلقائية يومية + نسخة يدوية + تصدير كامل JSON.
- تسجيل دخول بكلمة مرور (للاستخدام الداخلي فقط).

## التشغيل محلياً

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000` (كلمة المرور الافتراضية: `luckysky`).

## الإعدادات (متغيرات البيئة)

| المتغير | الوصف | الافتراضي |
| --- | --- | --- |
| `PORT` | منفذ الخادم | `3000` |
| `LUCKY_SKY_PASSWORD` | كلمة مرور الدخول | `luckysky` |
| `LUCKY_SKY_SECRET` | مفتاح توقيع الجلسات (JWT) | قيمة افتراضية — **غيّرها في السيرفر** |
| `LUCKY_SKY_DATA_DIR` | مجلد قاعدة البيانات والنسخ الاحتياطية | `./data` |

العملة ونسبة الضريبة واسم النشاط تُضبط من داخل البرنامج (صفحة الإعدادات).

## أين تُحفظ البيانات؟

كل البيانات في `data/lucky-sky.db` (SQLite بوضع WAL). **لا تُحذف تلقائياً أبداً.**
تُنشأ نسخة احتياطية يومية تلقائية في `data/backups/`، ويمكن أخذ نسخة يدوية أو تصدير
كامل في أي وقت. للنشر: اجعل `LUCKY_SKY_DATA_DIR` على تخزين دائم يُنسخ احتياطياً.

## التقنية

- الخادم: Node.js + Express.
- قاعدة البيانات: SQLite (`better-sqlite3`) مع فهارس لأداء سريع مع عشرات الآلاف من الصفوف.
- الواجهة: تطبيق صفحة واحدة (SPA) بـ HTML/CSS/JavaScript بدون أدوات بناء.
- استيراد إكسل: `xlsx` (SheetJS).
