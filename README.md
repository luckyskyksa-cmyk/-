# لاكي سكاي (Lucky Sky) — برنامج إدارة الديون

برنامج ويب بسيط واحترافي لإدارة ديون العملاء، للاستخدام الداخلي فقط.
تُحفظ كل البيانات في **سيرفر خارجي** (قاعدة بيانات مركزية)، فيمكن استخدامه من
عدة أجهزة (2–3 أجهزة) في نفس الوقت بدون فقدان البيانات ولمدى الحياة.

## المميزات

- إدارة العملاء (إضافة / تعديل / حذف / بحث).
- تسجيل الديون والتسديدات لكل عميل مع حساب الرصيد المستحق تلقائيًا.
- لوحة ملخص: إجمالي الديون المستحقة، عدد العملاء، إجمالي الديون، إجمالي المسدد.
- تسجيل دخول بكلمة مرور لحماية البيانات (للاستخدام الداخلي).
- زر **نسخة احتياطية** لتصدير كل البيانات كملف JSON في أي وقت.
- واجهة عربية (RTL) احترافية تعمل على أي جهاز عبر المتصفح.

## المتطلبات

- Node.js الإصدار 18 أو أحدث.

## التشغيل محليًا

```bash
npm install
npm start
```

ثم افتح المتصفح على: `http://localhost:3000`

كلمة المرور الافتراضية: `luckysky`

## الإعدادات (متغيرات البيئة)

| المتغير | الوصف | القيمة الافتراضية |
| --- | --- | --- |
| `PORT` | منفذ الخادم | `3000` |
| `LUCKY_SKY_PASSWORD` | كلمة مرور الدخول | `luckysky` |
| `LUCKY_SKY_SECRET` | مفتاح توقيع الجلسات (JWT) | قيمة افتراضية — **غيّرها في السيرفر** |
| `LUCKY_SKY_DATA_DIR` | مجلد حفظ قاعدة البيانات | `./data` |

> للنشر على سيرفر خارجي حقيقي: عيّن `LUCKY_SKY_PASSWORD` و`LUCKY_SKY_SECRET`
> بقيم قوية، واحرص على أن يكون مجلد `LUCKY_SKY_DATA_DIR` على تخزين دائم
> يُنسخ احتياطيًا. قاعدة البيانات ملف واحد باسم `lucky-sky.db`.

## التقنية

- الخادم: Node.js + Express.
- قاعدة البيانات: SQLite (ملف واحد، وضع WAL) — موثوقة وسهلة النسخ الاحتياطي.
- الواجهة: HTML/CSS/JavaScript بدون أي أدوات بناء.

## البيانات والحفظ

تُخزّن جميع البيانات في `data/lucky-sky.db`. لا تُحذف البيانات مع مرور الوقت.
احتفظ بنسخ احتياطية دورية عبر زر "نسخة احتياطية" أو بنسخ ملف قاعدة البيانات.
